# M05 routing and rounding contract

M05 independently implements published equations. `qar_uniform_fixture` is the fixed uniform integer-grid source fixture. `qar_fp4_adjacent` is a separate FP4 adaptation. `stochastic_shadow_forward` retains original FP32 W and samples forward weights; `stochastic_endpoint` retains codes and fixed scales, reconstructs W, and rounds each full original-W proposal. The latter may move multiple codes; only QAR enforces one-neighbor movement. None of these engineering fixtures establishes a defeated comparator, release reproduction, pilot relevance, or scientific selection.

## Source and dated clarification

The inspected reference is [arXiv:2609.21834v1](https://arxiv.org/html/2609.21834v1#S4.SS2), submitted 2026-09-18, §4.2 Eq.8 and Algorithm1. On 2026-10-04 root confirmed that feasibility masks magnitude **before** power normalization: `a=M*abs(u)`, then `b=a**gamma/mean_G(a**gamma)` for positive gamma and nonzero group power sum; otherwise `b=1`. Probability is `min(eta*M*abs(u)*b/uniform_spacing,1)`. `[100 outward-infeasible,1 feasible]` has feasible score two for gamma one, rather than `1/50.5`. The original condensed S24 row remains historical; its dated addendum and permanent registry metadata carry the binding correction.

No author QAR software repository or reuse grant was established. The arXiv nonexclusive distribution grant is not a software reuse grant, and its raw license byte snapshot/hash remains unresolved in the source audit. These are independently written local equations, not copied author software. Inspection supplies neither a release-parity result nor a legal assurance.

FP4 replaces uniform spacing with the actual physical directional adjacent gap. It adds selectable original-W backbones, full-proposal decoupled decay, fixed row-max scales, logical-step caching, optional full-last-axis Hadamard, and the shared LM transaction. Uniform-grid theory is **not** transferred to FP4. QAR treats minus the full storage displacement as its routing signal with eta one; group normalization cancels the common LR factor, giving the same probabilities as signal minus displacement/LR and eta LR for positive LR. LR zero yields no move while moments still update.

## Implemented choices and owners

The finite supported backbone families are original-W AdamW, project Muon, and the registered Muon+ normalization configurations. SOAP, Madam, and arbitrary unregistered rule compositions are unsupported today and need later owned implementation/evidence. This places no restriction on future B0 selection and does not defeat a blocked comparator. Auxiliaries use the shared explicit no-decay group and ordinary backbone rules.

All three LM controls require `row_fixed_max`, last-axis row grouping/power normalization, STE, and identity or the project full-last-axis orthonormal Hadamard (power-of-two input width). Configuration is complete finite canonical JSON; public sequences are lists. The named `quantizer` stream is a separately seeded **CPU torch.Generator**, with explicit uniforms transferred to the operand device. It never borrows the global or meta RNG. Public pure functions accept explicit uniform tensors for controlled coupling.

At the first logical transaction, grid scales initialize from the common input parent's **pre-conversion storage weights**. The adapter records original-W, storage-U and fixed-scale byte digests and the initialization source/step, without retaining a hidden W copy or residual. Exact numerical scales and zero-initialization flags survive endpoint conversion, rotated-back reconstruction and subsequent contexts. Scale digests are validated against retained context scales. A carried warm-parent context cannot bypass new-arm initialization. These digests identify the actual supplied parent arrays; external authenticated warm-parent/cursor/run lineage remains the caller's ordinary experiment responsibility and is not relabeled by this adapter.

The H06 pre-context hook runs after its snapshot and clock start. Endpoint conversion, sampling, adapter state, model caches, original-W moments and named RNG therefore roll back on failure. Endpoint W is an exact reconstructed mirror of authoritative FP4 codes/scales. Hidden extra adapter fields, missing endpoint inventories, forged scales/config/steps, or off-grid W fail trusted state validation. Shadow-forward state instead owns W through the ordinary model state and has no endpoint inventory. Completed observations are validated against the logical step counter. Both adapter types use finite local constructor registrations in H07; no serialized callable is accepted.

One shadow-forward weight sample is cached per logical batch; each microbatch rebuilds its backward graph from those cached codes. QAR and endpoint rounding sample once per projection at the commit boundary. The model cache retains the completed forward context, while the endpoint inventory retains the newly committed codes; they deliberately refer to opposite sides of the update. Primary evaluation always uses fresh deterministic nearest-even contexts on retained fixed scales, reads actual W, and advances neither state nor RNG.
