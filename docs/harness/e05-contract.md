# E05 attribution and extension boundary

Research cutoff is 3 October 2026; attempt dates use automatic current UTC.
`ralup.analysis.attribution` supplies `make_ablation_trials`,
`analyze_attribution`, `check_extension_eligibility`, and the attribution CLI.

```sh
python -m ralup run --phase explore --suite attribution --config configs/e05-attribution-prerequisites.json
```

This scientific invocation authenticates the indexed original E02 producer and
current E01/WP06 prerequisites, retains an immutable blocked disposition, and
returns 2. WP04 remains inconclusive/B0 null, WP06 NEEDS_REVISION, finalized
trained C/LR/B* and final learning/tuning budgets are absent, and WP08 has not
been attempted. No protected payload or new training is read or run. The real
integration owner is E01/reopened WP06, then E02; numerical SGD fixtures cannot
establish genuine trained/retuned attribution. The known original E02
administrative elapsed cost is disclosed separately from unknown scientific
paired/ancestor/common engineering costs and the current attempt receipt.

`configs/ablations/{actions,information,scales,noise,budgets}.json` are finite
prioritized proposal catalogs, with exact names/settings in
`baselines.registry.attribution_registry`. They include learned-LR [.25,32] and
shared-range [.25,4] controls with independently tuned backbone LR; static and
single actions; retrained alpha-zero, history/cell removals and matched-shape
history permutation; scale and rotation controls; matched-rate random
assistance, rounding/masking/damping; extra-data/compute ordinary baselines;
and privileged candidate-RMS norm matching. No full Cartesian campaign is
prescribed. S17's separately named first-order magnitude-preconditioned additive
control computes `c*z`, before exponential. It is distinct from Madam and does
not rescale the candidate exponential displacement.

Positive supported inputs are explicitly `synthetic-engineering` data-only JSON
artifacts. `ralup.attribution_parent.v1` authenticates current whole-source
identity and stream/model/budget/scorer/warm-start/continuation/normalizer/learning

positive local evidence or a predeclared falsifiable missing-condition diagnosis
may pass engineering gates. Unsupported, stale, unknown-budget or post-test
choices block; unfavorable and inconclusive evidence keep those dispositions.

contracts are separate. FP8 requires exact E4M3, MXFP4 E2M1/E8M0 block-32, and
W4A4 its own representation; none inherits an FP4 label. WikiText-2 is not
independent new-corpus transfer. A synthetic gate pass authorizes no native or
